# 👥 HR Employee Attrition Analysis

## Project Overview
End-to-end HR analytics project analyzing why employees
leave the company using Excel, SQL, and Power BI.
**Completed in 6 Days.**

## Tools Used
- 📊 Microsoft Excel — Data Cleaning, Pivot Tables, Dashboard
- 🔵 MySQL — 18 SQL Queries (Basic to CTE Level)
- 🟡 Microsoft Power BI — 4 Dashboards, 228 Visuals

## Dataset
- Source: Kaggle — IBM HR Analytics Attrition Dataset
- Rows: 1,470 Employees | Columns: 35
- Added Columns: AgeGroup, SalaryBand, AttritionRisk

## Power BI Dashboards
1. Attrition Overview Dashboard
2. Department Analysis Dashboard
3. Salary Analysis Dashboard
4. Risk Analysis Dashboard

## Key Insights
- Overall Attrition Rate: **16.12%**
- R&D Department has highest attrition — 133 employees
- 53.6% of leavers worked Overtime
- Employees earning below $3,000 have highest attrition
- 153 employees are currently High Risk

## SQL Concepts Used
WHERE, GROUP BY, HAVING, CASE WHEN,
Subqueries, JOIN, CREATE VIEW, CTE

## Project Structure
- `HR_Attrition_Project.xlsx` — Cleaned dataset
- `HR_Attrition.sql` — All 18 SQL queries
- `HR_Attrition_project.pbix` — Power BI dashboards
- `HR_Attrition_Report_RohanKumar.pptx` — Project report
